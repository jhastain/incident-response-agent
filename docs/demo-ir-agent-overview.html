STAGE 01llm

Classify

Reads raw alert text → category, severity, service, GCP project, and the alert timestamp that anchors every downstream query.

alert_classifier

Load context

Pulls similar past incidents and the affected service's infra map at the same time.

historical_contextinfra_context
STAGE 03parallel ×9

Investigate

Nine specialists hit every signal source simultaneously — logs, metrics, deploys, errors, infra health.

cloud_run_healthcompute_engine gcp_logginggcp_metrics datadogsentry deploy_correlationknown_issues teams_context
STAGE 04llm + tools

Synthesize

Cross-validates findings across sources, resolves conflicts, and re-queries to close gaps before it commits to a root cause.

synthesis_agent
STAGE 05conditional

Dispatch specialists

Only if the category needs depth — routes to SQL DBA, codebase, cache, auth, or Pub/Sub experts.

sql_dbacodebasecache auth_securitypubsub
STAGE 06llm

Report

Assembles a six-section, Teams-ready markdown report. Recommends only state-changing actions — read-only work is already done.

report_agent
STAGE 07independent

Verify

A separate scorer grades diagnosis, solution and efficiency, then sets a confidence tier — never HIGH without a human.

verification_agent
STAGE 08write

Persist

Dual-writes the incident to GCS and Firestore so the next investigation can learn from this one.

persistence_agent
sequential signal flow parallel fan-out (run at once) category-gated specialists wake on demand

SEV3 · RESOLVED

Ephemeral PR Pool Exhausted (0/3)

Root cause · moderate evidence

Normal concurrent demand hit the hard pool ceiling of 3, compounded by two slots held by 7-day-old PRs — one stale draft, one abandoned at alert time.

Key findings — evidence-backed
  • All 3 slots occupied: PR 105036 (draft, 7d), PR 105040 (abandoned), PR 105460 (~17h)
  • PR 105040 released its slot 94s after the alert — confirmed via ADO PR API
  • Cross-checked against Datadog build events + infra pool docs
Recommended actions — human decision
  • Expand pool ceiling 3 → 5+
  • Auto-reclaim draft PRs at the 7-day TTL
  • Add retry/alerting on cleanup-pipeline failures
