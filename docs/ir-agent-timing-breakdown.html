Phase breakdown

Tier-1 agents — are they actually parallel?

All start ~38-41s (good — they fire together) but each runs 90-138s. With per-agent sessions they overlap, yet the barrier is still the slowest agent (deploy_correlation 138s). Model = Haiku.

Fixed vs. remaining

Fixed: persistence 128s→~1s (code-only, no LLM); Tier-1 138s→63s (per-agent MCP sessions let Haiku agents truly parallelize).
Remaining: synthesis (~80s) + report (~70s) = ~150s of sequential Sonnet generation — the accuracy-critical reasoning stages. Getting under 180s would require moving these to a faster model (a direct accuracy tradeoff) plus handling the ~1/5 cold-start miss (retry wrapper already exists). Reliable ~250-300s is achievable without touching reasoning-stage accuracy.
