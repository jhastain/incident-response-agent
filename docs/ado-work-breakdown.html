Parallelization Opportunities

Can Run in Parallel

  • Phase 1: SRE infra (Pub/Sub, Bifrost, Sentry) runs parallel to DBA Firestore setup and CE scaffold
  • Phase 2: All 12 investigation agents can be developed in parallel once GCP wrappers + Bifrost client are done
  • Phase 3: Entra app (SRE) can start while Phase 2 CE work is in progress
  • Phase 4: DBA dedup queries can start as soon as Firestore setup is done (parallel to Phase 2 CE work)
  • Phase 5: KB queries (DBA) can start parallel to Phase 3/4 CE work

Must Be Sequential

  • 1.1 Repo must complete before any code work begins
  • 1.7 Firestore Setup must complete before Firestore Tools, dedup, or KB queries
  • Tier-1 agents must complete before Synthesis agent
  • ADK Wiring must complete before any Phase 6 testing
  • E2E Test must pass before Load Test
  • Entra App must complete before any Teams code
